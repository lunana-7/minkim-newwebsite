Writing should feel as frictionless as putting pen to paper.

## The Power of Plain Text

Plain text is durable. Twenty years from now, proprietary rich-text formats and complex databases might be obsolete, but plain Markdown files will remain completely readable by any machine.

### Formatting is Intuitive

You can use standard syntax:
- **Bold text** for emphasis
- *Italics* for subtle nuances
- `inline code` for technical terms

```javascript
// Clean syntax highlighting right out of the box

  return { title, content, publishedAt: new Date() };
```

Simply drop a new `.md` file into `src/content/blog/` and it instantly joins the archive.
