# Illustrated wardrobe maps

The wardrobe stage now displays generated portrait backgrounds for Maple Meadow, Cloudwood Forest and Moonlit Harbor. The central area is kept clear for the existing Mini sprite and pets. Label panels stay legible in both site themes. The old block sun, hills and plank platform are removed from this stage.

The other four world selections reuse their existing generated world artwork. Map selection still uses the existing travel event and player profile. No game mechanics change.

Built-in image generation was used. Original PNGs are retained in artwork/mini/wardrobe-scenes; web copies are in public/game-art/wardrobe. Full prompts and generation provenance are in artwork/mini/wardrobe-scenes/prompts.json. Ground anchors: meadow 86%, forest 78%, harbor 80% of preview height. The character remains a separate registered square canvas.
