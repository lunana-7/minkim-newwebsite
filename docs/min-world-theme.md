# Min’s World website theme

All pages share the same meadow palette and game-inspired panels through `src/world-theme.css` and the shared layout. Light mode uses sky blue, cream, sage and berry; dark mode uses a moonlit meadow palette.

- **Pixelify Sans:** headings, navigation, section titles and game controls.
- **Nunito:** introductions, article text, project details and smaller labels. Korean uses the available system Korean font for legibility.
- Fonts are hosted locally in `public/fonts/`, with their SIL Open Font License files beside them. No external font request is required.
- Journal banners are small SVG pixel landscapes generated by `src/banners.js`.
- The Mini portrait, shared walking character, appearance assets and saved profiles remain part of the same world.

The site preserves direct navigation, reading structure, project access and existing game behaviour. The background scenery is decorative and does not intercept clicks.
