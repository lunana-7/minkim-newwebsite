# In-game RPG windows

The field canvas remains visible behind every activity. Café, farm, market, ice cream and bakery open compact windows anchored inside the adventure viewport; the arrow button expands or contracts their window. Each has its own scroll area and persistent World return. Opening a window never scrolls the surrounding page.

NPC conversations use a bottom dialogue box with a large matching portrait. Dialogue is split into short pages and reveals progressively. Next/Enter first reveals an unfinished line, then advances pages, then performs the resident's final action. Previous revisits the preceding page. Reduced motion shows the full line immediately. Closing cancels the reveal timer. NPC action choices and saved player state retain their existing behavior.

The world map opens wide within the game. Its full atlas and destination icons are visible at once, with optional local trails, resources and residents folded in a separate side column. Map opening does not automatically pan the document. Only explicit travel-to-location actions retain their existing viewport positioning.

Game pages use the available desktop width. Movement pauses and controls become inert while a window is open, preserving the original playing/paused state for return. The surrounding website remains interactive and has no modal backdrop or body scroll lock. Existing study totals, crops, currency and kitchen orders are retained.
