# Mini’s little greetings

The bottom companion occasionally displays an English greeting such as “I’m glad you’re here!” in a short speech bubble. The first greeting appears after nine visible seconds; later messages arrive every 35–55 seconds and stay for 5.5 seconds. Global friendly lines are mixed with route-specific lines for the game, language garden, Wiki, Blog, Projects, About and Support, without immediate repeats.

The bubble follows Mini’s actual viewport position and stays within horizontal screen edges. It is outside the mirrored walking element, so text reads normally whichever way Mini faces. It ignores pointer input and has no automatic screen-reader announcement. It does not pause walking or award points.

Greetings wait while a menu, activity, emote, reward, drag or text input is active. Hidden tabs stop timers. Page exit clears timers, animation and subscriptions. Reduced motion adds no entrance animation. Visitors can turn greetings off in Mini’s menu; the preference persists across pages and tabs in browser storage.
