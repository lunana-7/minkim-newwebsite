# Mini favicon

Generated with the built-in image generation tool using `public/pixel-min.png` as the identity reference. The transparent portrait is packaged with nearest-neighbor pixel scaling into browser and touch icons:

- `public/favicon-mini.png` — 64 × 64 preview
- `public/favicon-mini-16.png` and `public/favicon-mini-32.png` — browser tab PNGs
- `public/favicon.ico` — 16, 32, 48, and 64 pixel representations
- `public/favicon.svg` — compatibility asset embedding the same pixel portrait
- `public/apple-touch-icon.png` — 180 × 180 touch icon

The page icon URLs use `?v=mini-2` to replace cached older icons.

## Generation prompt

Create a square website favicon portrait of this exact Mini pixel character. Use the reference for identity: brown eyes, very long black hair fading to brown, cute warm face. Crop the composition to her head and a tiny hint of cream dress at the neckline so the face is clearly readable at 16x16 and 32x32 browser tab sizes. Simple crisp true pixel art, strong clean dark silhouette, brown eyes and rosy cheeks. Centered head, fills about 90% of the square, small even transparent margin, genuinely transparent background. Simplify to a compact low-resolution pixel grid suitable for a favicon; do not create soft shading or anti-aliased illustration. No letters, no frame, no circle background, no extra objects, preserve the original character's identity.
