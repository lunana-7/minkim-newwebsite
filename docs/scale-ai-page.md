# Scale AI Growth Operations page

- URL after deployment: `https://www.datamin.org/scale-ai`
- Original document: `src/data/scale-ai/HFC_Growth_Operations.html`
- Route: `src/pages/scale-ai.ts`

The route serves the complete original HTML document, preserving its inline styles,
scripts, and embedded image. Google Fonts are loaded externally as in the original.
Edit the HTML file to update the page, then run `npm run build` and deploy through
the existing Vercel project. No DNS changes are required.

The response includes `X-Robots-Tag: noindex, nofollow, noarchive`, consistent with
the site's other role preparation pages. Anyone with the URL can still access it.

The source was copied from the supplied Claude scratch workspace; that original
file remains available there as a backup.
